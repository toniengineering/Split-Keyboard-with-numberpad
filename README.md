This is  a split keyboard with 43 keys a number pad. Each side of the split keyboard is running off of it's own xiao for the micro controller. The number pad will run off of a raspberry pi pico. The number pad has 20 keys, the first 17 will be the regular number pad keys and the extra 3 are for sound up, down and a pause button. The cad design for my PCB is a three part case that will connect using magnets that's why I have little rectangle in the side of them the magnets will be glued into them. The PCB will connect through screw holes in the case the half key board has three mounting holes while the number pad only has one but will still be screwed into the case. The case also has holes for the switches to pop out for keycaps and so I can press them. The case opens from the top and then should close with the PCB inside.
